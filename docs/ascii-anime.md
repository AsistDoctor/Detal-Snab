## Кадр 02 — Анимация: машет гаечным ключом

Листай кадры сверху вниз. Мозг сам дорисует анимацию — он молодец.

```
   (つ 🔧 )ノ        (ノ 🔧 つ)        (つ 🔧 )ノ        (ノ 🔧 つ)
    «Привет!»          «Пока!»          «Привет!»          «Пока!»
```

Бонус — анимация в стиле *«ушла на обед»*:

```
   ( ͡° ͜ʖ ͡°)つ🔧    →    ( −_－)ヾ    →    ...Zzz    →    (ง •̀_•́)ง БЭКЛОГ
```
